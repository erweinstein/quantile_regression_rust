# quantile_regression_rust

A Rust translation of the interior point quantile regression code of Koenker, Morillo and Eilers
(rq.m, rqic.m) and Koenker and Park (ipqr.m), and Rust replication code for Arellano and Bonhomme (2017).

Work in progress: the translation of rq.m and rqic.m is done and checked against the Python port in
[erweinstein/quantile_regression](https://github.com/erweinstein/quantile_regression); the rest follows.
See `NOTICE.md` for credit and the scope of the license.
